プライバシーポリシー

Memories Album（思い出アルバム、以下「本アプリ」）は、開発者本人と家族が個人的に使うためのツールです。本アプリにおける情報の取り扱いは、次のとおりです。

1. 取得する情報

本アプリは、利用者本人が許可した場合に限り、Googleアカウント（YouTube Data API）を通じて次の情報にアクセスします。

  • 本人のYouTubeチャンネルの名前と、アップロード済み動画の一覧・タイトル・説明文・公開範囲
  • 本人のチャンネルの再生リスト

2. 利用目的

  • 本人がアップロードした思い出の動画を探し、そのURLと公開範囲を本人のパソコン内のアルバムに記録するため
  • 本人のチャンネルに非公開の再生リスト「思い出アルバム」を作成し、思い出の動画を追加するため

これ以外の目的には使いません。広告・分析・AIの学習などにも使いません。

3. 保存場所

取得した情報と、Googleとの連携に必要な認証情報は、本人のパソコンの中にだけ保存します。外部のサーバーに送信・保存することはありません。

4. 第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。

5. 削除の方法

  • 本アプリの設定画面で「連携を解除」すると、パソコン内の認証情報を削除し、Google側の許可も取り消します
  • Googleアカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）からも、いつでもアクセスを取り消せます

6. Google API サービスのユーザーデータに関するポリシー

本アプリによるGoogle APIから受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。
